  Your own GPU behind OpenAI- and Anthropic-compatible APIs, with the cloud one alias away.<br>
  A Linux desktop app, and the clients of its API.

<p align="center"><a href="https://lmgw-dev.github.io/"><b>lmgw-dev.github.io</b></a></p>

| Project | What it is | Status |
| --- | --- | --- |
| [lmgw](https://github.com/lmgw-dev/lmgw) | The gateway. Runs local models in Podman containers on llama.cpp, audio.cpp and stable-diffusion.cpp, routes to cloud providers behind the same aliases, and serves it all through OpenAI- and Anthropic-compatible APIs, Realtime voice and MCP. | Released |
| [Kai](https://github.com/lmgw-dev/kai) | A voice client for the KDE Plasma desktop, built on lmgw's API: talk to your models from a global shortcut, keep one ongoing conversation, and let them use the desktop through MCP tools you control. [About Kai](https://lmgw-dev.github.io/kai/) · [Releases](https://github.com/lmgw-dev/kai/releases) | Released (0.2.0) |
| [Kai mobile](https://github.com/lmgw-dev/kai-mobile) | The Android client of lmgw, the phone side of Kai: voice calls and text in the same ongoing conversation, approvals by tap and notifications from your gateway, paired over lmgw's device link. [About Kai mobile](https://lmgw-dev.github.io/kai-mobile/) · [Releases](https://github.com/lmgw-dev/kai-mobile/releases) | Alpha, first release (0.1.0) |
| [lmgw-dev.github.io](https://github.com/lmgw-dev/lmgw-dev.github.io) | The project site. | |
